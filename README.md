# 🏏 IPL Data Analysis using Python & Power BI

## 📌 Project Overview

This project analyzes Indian Premier League (IPL) data to uncover meaningful insights into player performance, team performance, match statistics, and season trends using Python and interactive Power BI dashboards.

The project focuses on data cleaning, exploratory data analysis (EDA), and visualization to transform raw IPL datasets into actionable insights.

---

## 🎯 Objectives

- Analyze batting performance
- Analyze bowling performance
- Compare team performance
- Explore venue and match statistics
- Discover season-wise trends
- Build interactive Power BI dashboards

